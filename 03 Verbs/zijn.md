- **Meaning:** to be
- **Regular:** no
- **Perfectum with:** zijn

## Present (tegenwoordige tijd)
| Person | Form |
| --- | --- |
| ik | ben |
| jij / je | bent (ben jij?) |
| u | bent |
| hij / zij / het | is |
| wij / we | zijn |
| jullie | zijn |
| zij / ze | zijn |

## Past (imperfectum)
| Singular | Plural |
| --- | --- |
| was | waren |

## Perfectum
- Voltooid deelwoord: geweest
- Example: Ik ben in Amsterdam geweest.

## Examples
- Het [[huis]] is groot. — *The house is big.*
